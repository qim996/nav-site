# 轻舟导航 · 个人导航站

一个**单文件、纯前端、无后台**的个人网址导航站。莫兰迪米白/灰绿配色，部署到 GitHub Pages 即可在线使用，数据保存在浏览器本地，无需服务器。

## 功能特性

- **密码锁**：首次访问需输入密码（默认 `admin888`），可在设置中开启/关闭、修改密码
- **首页直接编辑**：无独立后台，首页长按卡片即可编辑、删除、拖动排序
- **实时北京时间**：顶部实时时钟（时:分:秒 + 日期星期）
- **实时天气**：默认显示秦皇岛天气（Open-Meteo 免费接口），设置中可改城市或隐藏
- **搜索栏**：默认必应搜索，可在设置中切换谷歌或自定义搜索引擎（`{q}` 占位符）
- **每日精选**：右侧每日自动更新少数派资讯（每天一次，本地缓存）
- **待办事项**：右侧面板勾选、行内编辑、删除，数据存本地
- **番茄钟**：25 分钟专注 / 5 分钟休息，到点提醒（WebAudio）
- **分类管理**：增删改分类、改分类颜色，卡片按分类筛选
- **自定义卡片颜色**：内置 8 种莫兰迪色 + 自定义取色器
- **favicon 自动拉取**：自动拉取网站图标，多源兜底（icon.horse / quickso）
- **数据导出 / 导入**：JSON 一键备份，换设备恢复

## 快速开始（GitHub Pages 部署）

1. 新建仓库（或使用本仓库），把 `index.html` 推送到 `main` 分支
2. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → 分支 `main` / 目录 `/ (root)` → Save
3. 等待 1-2 分钟，访问 `https://你的用户名.github.io/仓库名/`
4. 首次访问输入密码 `admin888` 进入

## 使用说明

- **添加网站**：顶栏「添加网站」，填写名称、网址、描述、分类、卡片颜色后保存
- **编辑 / 删除**：长按卡片约 0.5 秒进入编辑模式，右上角出现编辑 / 删除按钮
- **拖动排序**：编辑模式下长按卡片拖动即可换位
- **管理分类**：顶栏「分类」，可改名、改色、删除
- **设置**：顶栏齿轮图标，可改站点名、天气城市、搜索引擎、公告、密码、数据管理
- **右侧面板**：每日精选 / 待办事项 / 番茄钟 三个标签切换
- **锁定**：顶栏锁图标可随时重新锁定页面

## 默认密码

> 访问密码默认 `admin888`，进入后可在「设置」中修改或关闭密码。
> 密码与所有数据仅保存在本机浏览器 localStorage 中，不上传服务器。

## 技术说明

- 单文件 `index.html`，原生 HTML / CSS / JavaScript，无构建、无后端依赖
- 数据存于 localStorage，导出 JSON 可备份迁移
- 天气：Open-Meteo 免费 API（无需 Key）
- 资讯：少数派开放接口（每日一次，本地缓存）
- 网站图标：icon.horse 为主源、quickso 为备用源，域名保留 www 以提高拉取率
- 字体：Noto Sans SC（在线加载）

## 更新维护

修改 `index.html` 后 push 到 `main` 分支即可，GitHub Pages 会自动重新部署。
